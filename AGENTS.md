# CABUILD project instructions

Before running project commands or inspecting/editing implementation files in this repository, read and apply [.agents/skills/cabuild-website-delivery/SKILL.md](.agents/skills/cabuild-website-delivery/SKILL.md). This applies to every CABUILD task, including read-only reviews, fixes, tests, Git operations and deployment. Read the skill once per task; do not reread it before each command.

Follow its Git synchronization, validation, independent UAT, deployment verification and project-log workflow. Apply each release gate when relevant: read-only work does not require an empty commit or deployment. Preserve existing user authorization and all unrelated changes.
